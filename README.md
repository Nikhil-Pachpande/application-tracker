# Job Application Tracker
This is a Chrome extension that helps users manage and track their job applications. It allows users to add, edit, and delete job application details, including job title, company, status, and more. The application data is stored locally in the browser for easy, offline access.
This web browser extension is published on Chrome web store at ```https://chromewebstore.google.com/detail/job-application-tracker/licnjkklehklajhikiapfdojoofafclk```.

## Features
- Add details like Job ID, Job Title, Company Name, Location, Link, Resume, and Status.
- Modify application details or remove applications as needed.
- All job application data is stored locally using localStorage for offline access.
- Displays the total number of applications at the bottom of the list.
- Easy-to-use interface for managing job applications.

## Technologies Used:
- HTML for structuring extension's popup interface
- CSS for styling the layout
- JavaScript to handle application logic, form submissions, and data storage
- localStorage for persistent, client-side data storage for the application details
 
## Installation:
- Download or clone this repository.
- Go to chrome://extensions/ in Chrome.
- Enable Developer mode in the top right.
- Click Load unpacked and select the folder where you saved the extension files.
- The Job Application Tracker extension icon will appear in your Chrome toolbar.
